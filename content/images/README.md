# Artwork images

Web copies of the artwork images referenced by the intake spreadsheet: JPEG, sRGB, at most 5,000 px on the long side, under 20 MB, named `year-title.jpg` (lowercase, hyphens, no spaces).

Upload here through GitHub's web interface (Add file, Upload files) or by git. The importer attaches each file to its product by name, so filenames must match the `images` column exactly.
